## 模型与界面实测

- **DeepSeek 官方 API 已完成真实联调**：`https://api.deepseek.com`，模型 `deepseek-flash`。核对依据为[官方工具调用文档](https://api-docs.deepseek.com/guides/tool_calls/)。真实凭据只保存在被忽略的后端 `.env`，文档和前端均不包含密钥。
- 官方模型完成最小工具调用验证，以及真实任务路由的完整 8 用例流程（运行 #5 / 任务 #4），包含人工补充、确认、真实请求、分析和历史保留。
- 官方模型在**前后端生产构建**上通过真实浏览器完整流程（项目与运行 #6 / 任务 #5）：选择、补充、双重确认、执行、报告、Excel、原列表来源和历史查看。
- 官方模型还实际生成了 2 条文字需求草稿，经审核保存到用例目录。草稿浏览器回归使用模拟 API，覆盖编辑名称、步骤及优先级、移除草稿、审核失效、保存失败重试与放弃重开；不以模拟测试代替真实模型联调。
- Agent 和草稿面板在 320、768、1024、1440 像素宽度验证；新增面板无横向溢出，浏览器未捕获页面脚本错误。最终报告另行检查了移动端、桌面端和键盘焦点。
- 本地兼容代理此前也通过完整流程，实际代理模型为 `gpt-6.1-sol`。官方验证与代理验证分别记录，未混用结论。

## 第一版范围与限制

- 单个 Agent、HTTP/REST 功能测试，后端按单进程运行；未包含浏览器 UI 自动执行、负载测试或分布式调度。
- 每次最多 20 条用例；准备最多 6 次、执行最多 16 次模型调用；每阶段最多 64 次工具调用、5 分钟。HTTP 单请求最多 30 秒、响应正文最多 1 MiB，不自动跟随重定向。
- 认证值由后端环境变量解析；模型与界面保存脱敏证据。接口和业务规则缺失时保留待确认问题，由用户确认预期及前置条件。
- 已完成的执行证据逐条事务保存；模型失败保留已执行结果并标记其余未执行。服务重启将运行中任务标记中断，不自动重发可能有副作用的请求。
- 本次覆盖本地演示接口及上述权限、异常测试，没有声称验证任意第三方业务接口或生产部署。目标要求的官方模型、本地完整流程、报告、历史与构建均已验证。
